## Concepts studied | Conceitos estudados

### Introduction to AI | Introdução à IA

- Artificial Intelligence is the broad field of systems that perform tasks associated with human intelligence. Machine Learning is a subset that learns patterns from data, while generative AI creates new content from prompts.
- Inteligência Artificial é o campo amplo de sistemas que executam tarefas associadas à inteligência humana. Machine Learning é um subconjunto que aprende padrões a partir de dados, enquanto IA generativa cria conteúdo novo a partir de prompts.

### Select AI

- Select AI lets users interact with data and LLMs through natural language and SQL. In supported Oracle AI Database and Autonomous AI Database environments, it can help generate, run, and explain SQL; it also supports patterns such as retrieval-augmented generation (RAG).
- Select AI permite interagir com dados e LLMs por linguagem natural e SQL. Em ambientes Oracle AI Database e Autonomous AI Database compatíveis, pode auxiliar a gerar, executar e explicar SQL; também suporta padrões como retrieval-augmented generation (RAG).

### AI Vector Search | Busca Vetorial com IA

- AI Vector Search represents content as vector embeddings and finds semantically similar results instead of relying only on keyword matching. Oracle AI Database provides the `VECTOR` data type and vector indexes for this type of workload.
- A Busca Vetorial com IA representa conteúdo como embeddings vetoriais e encontra resultados semanticamente semelhantes, em vez de depender apenas de palavras-chave. O Oracle AI Database fornece o tipo de dados `VECTOR` e índices vetoriais para esse tipo de carga de trabalho.

### Oracle Machine Learning | Oracle Machine Learning

- Oracle Machine Learning provides in-database machine learning capabilities through interfaces such as SQL, PL/SQL, Python, and R. Keeping data and model operations close to the database can reduce unnecessary data movement.
- Oracle Machine Learning fornece recursos de machine learning no banco de dados por interfaces como SQL, PL/SQL, Python e R. Manter os dados e as operações de modelo próximos ao banco pode reduzir movimentação desnecessária de dados.

### Oracle AI Database Private Agent Factory

- Private Agent Factory is Oracle's no-code platform for building and deploying AI agents and workflows that can connect to enterprise data and tools. It is a separate Oracle product capability with its own deployment, model, and security requirements.
- Private Agent Factory é a plataforma no-code da Oracle para criar e implantar agentes e fluxos de trabalho de IA que podem se conectar a dados e ferramentas corporativas. É uma capacidade de produto Oracle separada, com requisitos próprios de implantação, modelos e segurança.
