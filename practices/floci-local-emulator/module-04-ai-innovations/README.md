# Module 4 local emulation plan | Plano de emulação local do Módulo 4

## Purpose | Propósito

Create transparent, local-first practice around supported OCI API patterns while studying the Module 4 AI Innovations concepts.

Criar prática transparente e local-primeiro em torno de padrões de APIs OCI suportadas enquanto os conceitos de Inovações em IA do Módulo 4 são estudados.

## Directly unsupported topics | Tópicos diretamente não suportados

- Select AI.
- AI Vector Search in Autonomous AI Database.
- Oracle Machine Learning.
- Oracle AI Database Private Agent Factory.

These are not claimed as Floci executions. / Estes não são apresentados como execuções no Floci.

## Planned local equivalents | Equivalentes locais planejados

- Object Storage for dataset-like object handling.
- Vault and KMS for encryption and key-management patterns.
- Streaming and Queue for event and message-flow patterns.
- Functions only if the local Floci Functions environment is verified first.

No item above is marked as executed until a real local command output is captured. / Nenhum item acima é marcado como executado até que uma saída real de comando local seja capturada.

## Evidence rule | Regra de evidência

Use `localhost:4599` only for Floci local evidence. OCI tenancy execution, IAM behavior, billing, managed database features, vector indexing, and AI services remain outside this laboratory scope.

Use `localhost:4599` somente para evidências locais do Floci. Execução em tenancy OCI, comportamento de IAM, cobrança, recursos de banco gerenciado, indexação vetorial e serviços de IA permanecem fora do escopo deste laboratório.
